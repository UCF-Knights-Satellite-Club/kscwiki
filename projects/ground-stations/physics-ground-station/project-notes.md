# Project Notes

Notes from earlier work at the station. See [Hardware](hardware.md) for the equipment in use now.

## September 23, 2025 meeting notes

These notes describe the old setup. The antennas have changed since this meeting; the 2 m antenna is now installed.

### Antenna notes

* Coax attenuation may be a problem because the coax run is long for the dish antenna frequency.

### Radio and software notes

* A future 2 m antenna may require an N-female to PL-259 adapter.
* Future work may include connecting radios to the UCF Ethernet network for remote connection.
* FLRig can interface with and control the transceiver.
* Orbitron can be used for rotator control.
* SDR Console can be used for SDR control.
* DHCP was off during testing.
* Ethernet was connected from the transceiver to the PC.
* The PC successfully pinged the radio.
