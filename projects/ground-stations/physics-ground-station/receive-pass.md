# Run a receive pass

{% hint style="warning" %}
**Draft; last tested: not recorded.** Use with an experienced operator. Recording controls, storage, parking position, and shutdown order still need confirmation.
{% endhint %}

1. **Prepare.** Confirm lab access and station readiness with the operator.
2. **Start up.** [Connect a computer](pc-setup.md), check [computer assignments](station-computers.md), and follow the [IC-R8600 setup notes](radio-software.md).
3. **Choose a pass.** Check orbital data, station location, clock, receive frequency, and mode. Note the satellite and pass times.
4. **Track and record.** Confirm pointing with the operator and test a short recording before the pass. If antenna direction disagrees with the indicated position, pause tracking and ask the lead to assess [calibration](calibration.md).
5. **Save.** Verify the recording opens. Log the satellite, UTC time, operator, receiver, frequency/mode, file location, and outcome.
6. **Shut down.** With the operator, stop tracking, park the antennas, and follow the approved shutdown order. Save work before shutting down computers; leave unresolved issues in the session notes.
