# Run a receive pass

{% hint style="warning" %}
**Draft — use with an experienced operator.** There is no recorded test date. The recording steps, save location, antenna resting position, and shutdown order still need to be checked.
{% endhint %}

1. **Prepare.** Arrange lab access and ask the operator whether the station is ready to use.
2. **Start up.** [Connect a computer](pc-setup.md), check [which computer does what](station-computers.md), and follow the [IC-R8600 setup notes](radio-software.md).
3. **Choose a pass.** Check that the tracking software has up-to-date orbit information, the right station location, and the correct time. With the operator, choose the radio frequency and signal mode for the satellite. Note its name and pass times.
4. **Track and record.** Ask the operator to check the antenna direction, then make a short test recording before the pass. If the antennas point somewhere different from the direction on the controller display, stop tracking and ask the lead to check [calibration](calibration.md).
5. **Save.** Open the recording to check that it saved correctly. Write down the satellite, time in UTC, operator, radio, frequency and mode, file location, and whether you received a signal.
6. **Shut down.** With the operator, stop tracking and move the antennas to their usual resting position. Save your work and follow the station’s shutdown steps. Leave a note about any problems for the next person.
