## What is a ground station

A ground station uses antennas, radios, and computers to communicate with satellites.

**Receive** is listening. **Transmit** is talking. Anyone at a station can watch a receive pass. Transmit is only legal with a licensed amateur as control operator.

### Four jobs on a pass

1. **Point** — the rotator aims the antennas at the satellite.
2. **Hear** — the radios take the signal off the coax.
3. **Track** — the computers run the pointing and radio software.
4. **Record** — the operator keeps what the pass produced.
